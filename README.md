# 🎭 Bizarre Excuses

Расширение для Visual Studio Code, которое генерирует случайные отмазки — на случай просроченных дедлайнов, забытых лабораторных и других ситуаций, когда нужна веская причина.

**Автор:** Волков Даниил Дмитриевич, М3111

**Репозиторий:** https://github.com/Loiokf/Bizarre-Excuses

> *«Дедлайн — это не срок, это рекомендация».*
> — народная мудрость, передаваемая из семестра в семестр

---

## 🚀 Зачем это нужно

Каждый студент хотя бы раз оказывался в ситуации, когда до сдачи оставалось несколько часов, а причина опоздания ещё не придумана. **Bizarre Excuses** решает эту проблему: вместо того чтобы судорожно вспоминать, почему не работает Git, достаточно нажать одну кнопку — и готовая отмазка уже в буфере обмена.

Плагин встроен прямо в редактор, не отвлекает от работы и всегда под рукой.

---

## ✨ Возможности

- **Элемент в строке состояния.** В правом нижнем углу VS Code отображается звёздочка — это точка входа в плагин.
- **Случайная отмазка.** При вызове команды плагин выбирает случайную фразу из встроенной коллекции.
- **Уведомление с кнопкой.** Отмазка показывается во всплывающем уведомлении с кнопкой «Копировать».
- **Копирование в буфер обмена.** По нажатию кнопки текст отмазки попадает в буфер — готовый к вставке в чат, письмо или комментарий к коммиту.
-  **Команда в палитре команд.** Доступна как `Bizarre Excuses: Get Excuse` через `Ctrl+Shift+P`.
- **Корректное освобождение ресурсов.** Все подписки регистрируются в `context.subscriptions` и освобождаются при деактивации расширения.

## 📦 Установка

### Из файла VSIX

1. Скачайте файл `bizarreExcuses-0.0.1.vsix` из раздела **Releases** репозитория.
2. Откройте панель расширений в VS Code (`Ctrl+Shift+X`).
3. Нажмите `...` в правом верхнем углу панели и выберите **Install from VSIX...**
4. Укажите скачанный файл и перезагрузите VS Code.

### Из исходного кода

```bash
git clone https://github.com/Loiokf/Bizarre-Excuses.git
cd Bizarre-Excuses
npm install
npm run compile
```

Затем нажмите `F5` в VS Code — откроется окно `Extension Development Host` с подключённым расширением.

## 🎮 Использование

**Способ 1 — через строку состояния.**
В правом нижнем углу VS Code находится звёздочка. Нажмите на неё — появится уведомление с отмазкой.

**Способ 2 — через палитру команд.**
Нажмите `Ctrl+Shift+P` (или `Cmd+Shift+P` на macOS), введите `Bizarre Excuses: Get Excuse` и выберите команду.

**Копирование отмазки.**
В уведомлении нажмите кнопку **«Копировать»** — текст будет помещён в буфер обмена.

## 💬 Примеры отмазок

Встроенная коллекция охватывает несколько жизненных категорий:

- **Техническая:** «Git съел мой коммит. Серьёзно, я видел, как он это делал».
- **Домашняя:** «Кот лёг на клавиатуру и удалил папку `src`. Я не виноват».
- **Погодная:** «Была магнитная буря, и мой код не компилировался по погодным условиям».
- **Абсурдная:** «Меня похитили инопланетяне. Они тоже не смогли запустить мой проект».
- **Классическая:** «Собака съела домашку. Теперь она ест и дедлайны».

Коллекцию легко расширить — достаточно добавить новую строку в массив в `src/excuses.ts`.

## 🧠 Как это работает

1. В `package.json` в секции `contributes.commands` объявлена команда `bizarreExcuses.getExcuse`. IDE узнаёт о ней до запуска кода.
2. При активации расширение в `extension.ts`:
   - регистрирует обработчик команды через `vscode.commands.registerCommand`;
   - создаёт элемент в строке состояния через `vscode.window.createStatusBarItem` и привязывает его к команде.
3. При вызове команды:
   - из модуля `excuses.ts` запрашивается случайная отмазка;
   - через `vscode.window.showInformationMessage` показывается уведомление с кнопкой «Копировать»;
   - при нажатии кнопки текст копируется в буфер обмена через `vscode.env.clipboard.writeText`.
4. При деактивации все ресурсы освобождаются через `context.subscriptions`.
